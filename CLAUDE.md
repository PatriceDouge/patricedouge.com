# patricedouge.com

Next.js 16 App Router, React 19, TypeScript strict, Tailwind CSS 4, pnpm only.
Fragment Mono at a single weight: never add font weights — emphasis is colour.

All prose lives in `content/`. Read `content/README.md` before adding or editing
any copy. Pages under `app/` carry no text of their own.

Verify with `pnpm lint`, `pnpm exec tsc --noEmit`, and `pnpm build`.
